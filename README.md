> ### 📌 关于本项目的初衷与立场声明（写在前面）
> 
> 1. **纯粹的技术求真，绝非针对任何厂商**  
>    本项目由几位普通的技术极客与开源爱好者自发建立。当时在灰测中偶然捕获到特殊的格式特征与网络响应后，我们仅仅是作为技术人员记录下了可复现的客观现象。然而，随之而来的是大量未经验证的人身攻击、造假指责与恶意扣帽。我们建立证据墙的唯一动机，是为了**自证清白、记录客观事实**，证明我们当时发现的异常现象是真实存在的技术抓包，而非凭空捏造。
> 
> 2. **关于“蒸馏”技术：我们始终持开放与支持态度**  
>    在机器学习领域，模型蒸馏（Knowledge Distillation）是一项公认、成熟且极其高效的工程优化与能力迁移手段。我们完全支持并乐见国内 AI 团队采用各种技术手段吸收前沿经验、降低推理成本、加速技术迭代，为中文开发者带来更强大、更亲民的模型。技术探索本身没有任何原罪。
> 
> 3. **免责与反网暴声明**  
>    本项目所有内容均基于公开网络抓包、公开学术/技术讨论，以及权威第三方机构发布的公开安全报告，不涉及任何主观捏造或非法商业目的。请勿将纯粹的学术与工程现象政治化、意识形态化。我们坚决反对任何形式的开盒、网络暴力、抹黑或无端人身攻击，并保留通过法律途径追究侵权行为的权利。
